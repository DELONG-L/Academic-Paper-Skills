### Unified academic workflow

The previous public release split default policy from a strict house-style set.
This update uses one shared workflow: `integrity-core` and `academic-defaults`,
with applicable hard requirements and adaptable presentation preferences.

- Add argument and paragraph-structure review, evidence-to-results guidance,
  revision closure, standalone review excerpts and template migration.
- Strengthen direct, supported writing and contextual prose diagnostics.
  Preserve material conditions without requiring repeated anticipatory defenses;
  prohibit detector-based authorship or readiness judgments.
- Allow authorized citation verification, bibliography fixes and internal skill
  handoffs without repeated permission requests. Ordinary edits remain scoped.
- Retain author-side manuscript review and responses; assigned peer review is
  outside this bundle.
- Keep source-bound semantic evidence, deterministic failure precedence and
  manual-check authority. Separate uncertain lint hints from definite failures.
- Replace fixed venue/font/chart assumptions with actual requirements and
  final-size inspection. Allow explicit supplied prose values, shared plotting
  entrypoints and suitable export formats; retain data and artifact traceability.
- Align registry rules, task references, examples, executable diagnostics,
  bilingual documentation and CI. Add regression cases for legitimate text and
  artifacts that must survive checking as well as actual failures.
