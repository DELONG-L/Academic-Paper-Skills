# README cover generation prompts

Generated with the built-in ImageGen tool. These are conceptual editorial covers, not manuscript screenshots or research results. English was generated and refined; Chinese localizes the refined English cover.

## English generation

Use case: ads-marketing / scholarly editorial cover.
Create a refined wide cover image for the GitHub README of Academic Paper Skills, a set of four coordinated Codex skills for author-side academic manuscript work. Aspect ratio 2.4:1, approximately 1920 by 800. Crisp flat print design, warm ivory paper #F4F1E8, deep forest green #173F35 and a very small warm ochre accent. Preserve the project's established green scholarly identity.
Composition: left 43% is an uncluttered typographic title block, right 57% is a precise editorial arrangement of four manuscript sheets laid out as an integrated publication spread. Thin rules, large margins and subtle overlapping edges provide structure. Each of the four sheets has ONE large readable title and a few abstract printer's rules or clearly nonnumeric markup strokes. Treat these as conceptual editorial motifs, never fake scientific results. No charts, no axes, no plotted trends, no real manuscript, no lorem ipsum. Four sheets are equal in importance and independent: no arrows, numbering, checkmarks or fixed sequence.
Typography: high contrast elegant readable serif for the main project name, clean sans-serif for four task labels. Large enough to remain readable at GitHub article width. No tiny footnotes.
Exact text only, all English:
Main title on left across two or three balanced lines: "Academic Paper Skills"
Small line beneath main title: "Four skills. Shared evidence."
Four sheet labels on the right:
"Writing"
"Figures & tables"
"Author review"
"Requirements"
Do not add any other words, symbols that look like credentials, badges, logos, seals or decorative props. No gradients, no heavy shadows, no rounded dashboard cards. The image should feel like the opening spread of a considered academic field guide.
