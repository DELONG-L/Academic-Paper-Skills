# 安装与使用

[English](getting-started.md) · 简体中文 · [首页](../README.zh-CN.md)

## 安装技能指令

将 `paper-writing`、`paper-figures-tables`、`paper-review`、`paper-policy` 一起安装。它们通过相邻目录名互相引用，请保留这些名称。

按[首次安装命令](../README.zh-CN.md#quick-start)操作。如果设置了 `CODEX_HOME`，使用其中的 `skills/`；否则使用 `~/.codex/skills/`。只复制四个技能目录，不要把整个仓库作为一个技能安装。安装后新建 Codex 任务，并在调用相应技能时提供源材料。

## 按任务准备工具

| 任务 | 所需环境 |
|---|---|
| 读取和应用技能指导 | 支持本地技能的 Codex |
| 运行规则检查程序 | Python 与 `requirements-policy.txt` 中的依赖 |
| 运行绘图／图像辅助程序 | 另行安装 `requirements-figures.txt` 中的依赖 |
| 设计新的概念图 | 可用的 `imagegen` 技能与内置图像工具，之后进行 SVG 重建 |
| 编译已有 LaTeX 项目 | 与稿件及其宏包兼容的编译器 |

Python 依赖建议安装到虚拟环境。推荐 Python 3.10+，自动测试使用 3.11。Python 环境本身不提供图像生成工具或 LaTeX 编译器。ImageGen 不可用时，技能会明确指出缺失阶段，不会冒充完成设计。

## 保留本地改动的升级方式

1. 在仓库副本中运行 `git pull --ff-only`。
2. 比较已安装技能与仓库版本，保留本地定制。
3. 将四个已安装目录移到独立备份位置，备份位置应在正在使用的 `skills/` 目录之外。
4. 按安装命令复制完整的新目录，再有选择地恢复兼容的定制。
5. 新建 Codex 任务。

完整替换可以避免已经删除的参考文件或废弃规则残留。升级时不要直接覆盖合并目录。仓库说明与品牌资源无需复制进技能目录。

## 提供有效上下文

- **写作：** 当前段落、研究问题、来源证据和修改范围。
- **图表：** 稿件背景、真实数据或明确数值、目标版面与会议限制。
- **审阅：** 稿件版本、审稿意见，以及需要核验的修改或证据。
- **规则检查：** 论文类型、阶段、源文件和附带来源的会议指南。

源文件检查通过与科学判断成立是不同状态。证据缺失时应明确记录，不能用看似合理的内容填补。

## 常见问题

| 现象 | 检查方法 |
|---|---|
| 找不到技能 | 每个安装目录应直接包含 `SKILL.md`；检查 `CODEX_HOME` 并新建任务。 |
| 相邻技能引用不存在 | 一起安装四个技能并保留名称。 |
| 出现 `ModuleNotFoundError` | 激活安装相应依赖时使用的环境。 |
| 更新后仍出现旧规则 | 比较已安装文件，备份后完整替换目录。 |
| 生成图中的标签或箭头错误 | SVG 重建时按内容定义修正，再检查实际渲染。 |
| 子图数量与可读性冲突 | 重组有依据的比较、调整版面或改用表格；无法解决时明确报告。 |

报告可复现问题时，请提供技能名、最小输入、预期和实际结果，以及相关工具版本。公开报告中应移除未发表或保密的稿件内容。
