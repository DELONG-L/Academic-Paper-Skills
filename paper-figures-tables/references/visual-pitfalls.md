# 科研图表的语义与呈现检查

根据图中实际关系判断问题。以下提供诊断与修复选择；图型名称、样本量阈值或个人排版习惯不构成自动失败。说明具体误读风险并完成有依据的修正，避免用假想审稿人反应要求补做实验。

| 项目 | 实际问题 | 修复选择与适用例外 |
|---|---|---|
| P1 汇总与分布 | 汇总是否掩盖与结论相关的分布、n 或变异？ | 有原始数据时按需展示点、区间或分布；只有可信汇总时可以如实作图，不要求不存在的原始点。 |
| P2 两条纵轴 | 不同尺度是否制造未经支持的同步或差异？ | 独立变量优先分面或直接画关系；同一量的明确单位换算可以用第二轴。 |
| P3 比例与三维图 | 角度、透视或遮挡是否妨碍所需比较？ | 精确比例优先条形图；少量构成可用清楚标记的饼图；真实几何、曲面或空间关系可以保留三维表现。 |
| P4 轴范围 | 长度或面积是否夸大差异？ | 柱长通常采用零基线；点图或折线可用清楚标记的局部范围。对数、断轴、放大图的范围和转换须可见，不强制所有概率图从零开始。 |
| P5 连续色阶 | 颜色能否映射回数值或区间？ | 使用有单位的 colorbar、共享色标或等效明确标注；可比面板采用一致映射，或说明不同尺度。 |
| P6 连线 | 线表示顺序、连续变化、配对关系还是无关类别？ | 有序趋势和同一个体的配对连线都有效；不无说明地连接无序类别并暗示连续变化。 |
| P7 类别颜色 | 类别可否区分，同一含义跨图是否稳定？ | 直接标注、线型、符号或分面；不为满足颜色上限合并科学上不同的组。 |
| P8 图例 | 映射不明或遮挡证据？ | 图例或直接标注均可，使用可理解标签并移开遮挡项。 |
| P9 误差含义 | SD、SEM、CI、IQR、须线或重复次数是否混淆？ | 说明实际统计量、分析单位和适用的 n；误差展示不自动要求显著性检验。 |
| P10 装饰 | 强调是否误导或增加阅读负担？ | 移除无用背景和阴影；保留有解释作用的面板标题、注释与分组。 |
| P11 格式 | 导出是否改变内容或有效分辨率？ | 依据真实投稿要求和最终渲染；混合矢量与栅格有效，JPEG 或字体类型本身不证明科学错误。 |
| P12 多面板 | 面板是否有共同问题、清楚顺序与一致语义？ | 相关证据可以共图；不相关且难以比较时拆分，无需每个面板支持同一个单句结论。 |
| P13 可访问性 | 关键类别是否仅靠难以区分的颜色表达？ | 添加非颜色线索，查看灰度或必要的色觉模拟；工具按可用环境选择。 |
| P14 色图 | 数值顺序是否被亮度或边界扭曲？ | 顺序量优先感知均匀色图；偏离有意义中心的量可用发散色图；有科学含义的领域映射可保留并解释。 |
| P15 显著性 | 符号是否对应实际检验、比较和校正？ | 只标有支持的结果，不从区间是否重叠自动推出任意显著性结论。 |
| P16 缺字 | 中文、负号、希腊字母、上下标是否正确？ | 检查实际字体和输出；使用支持字符的字体或正确数学排版，不改变符号含义。 |
| P17 裁切遮挡 | 数据、标签、区间是否被截断？ | 从来源或布局修复，重新导出并查看，不靠涂抹数据改善版式。 |
| P18 子图标记 | 编号、定位和正文引用是否一致？ | 对齐关联面板并更新引用，保证对应关系可恢复。 |

`source-data-and-statistics.md` 负责来源和汇总，`chart-selection.md` 辅助选择图型，`visual-qa.md` 负责实际查看。实验设计或统计分析变更仍需要其本来的任务授权。
