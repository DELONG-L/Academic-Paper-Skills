# 获取与应用目标图表规范

用于目标期刊、会议、年度和阶段已经明确的图表交付。通用绘图不必先确定投稿去向；使用稿件当前栏宽或合理的临时尺寸即可。

## 获取当前要求

核对作者指南、实际提供的模板与投稿阶段。不同子刊、会议和年份可能不同，不从出版社名称套用固定尺寸、字体、DPI 或子图标签表。

| 字段 | 核对内容 |
|---|---|
| 范围 | 刊物或会议、年份、文章类型、初稿或最终稿 |
| 尺寸 | 单栏/通栏宽度、高度、边距；模板中的实际可用区域 |
| 字体 | 最终有效字号、字符覆盖、嵌入或轮廓要求 |
| 格式 | 接受的矢量、位图、复合图和源文件格式 |
| 栅格内容 | 最终放置尺寸下的像素分辨率及明确的 DPI 要求 |
| 视觉约束 | 颜色、灰度、子图编号、图注位置等明确要求 |
| 来源 | 官方 URL 或本地模板路径、核查日期、对应条款 |

本地模板可以确定其实际版式，不能自动证明投稿截止日期、上传限制或其他流程要求。冲突时采用当前适用的正式来源；只对影响交付的未解冲突请求必要决定。

## 应用到实际文件

从最终宽度推导源尺寸与字号。若源宽为最终宽的三倍，源 24pt 大约对应最终 8pt；其他比例同样有效，最终渲染是判断依据。

精确图保留可重建的数值来源与生成过程。优先导出含矢量文字、线条的 PDF/SVG；必要栅格层可以保留在矢量容器中。针对最终投递格式做转换和查看，不为追求“纯矢量”重画实际数据。

内置 `setup_style` 的 journal 参数是样式预设，不是当前官方规范。根据已确认要求覆盖参数，检查本地字体实际可用性和最终字符渲染。使用 `scripts/setup_style.py --list-fonts` 查看字体，不因某个预设不可用就阻断可完成的作图。

按 `visual-qa.md` 和 `publication-checklist.md` 查看实际导出与放置后的文件。正式合规判断遵循 `../../paper-policy/references/authority-model.md` 的来源要求。
