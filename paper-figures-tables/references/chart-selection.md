# 根据数据与问题选择图型

用于图型尚未确定或现有图不能清楚表达研究关系时。已明确且适当的作图请求可以直接执行，不必重新询问主张或加载完整决策流程。

## 先判断表达关系

结合用户问题、变量含义、数据单位、依赖关系和可用精度选择。同一数据可用于分布、组间比较、配对变化或时间趋势；展示方式不能悄悄改变研究问题。

| 目的 | 可选图型 | 决策要点 |
|---|---|---|
| 一维分布 | 点图、直方图、ECDF、箱线、KDE/小提琴 | 原始点、分箱和平滑保留什么；离散变量、边界和小样本影响平滑解释。 |
| 组间比较 | 点与区间、箱线/小提琴、柱状、表格 | 展示总量、均值、个体还是分布；只有汇总时不伪造分布。 |
| 配对变化 | 配对连线、差值点图或区间 | 同一个体/运行的身份对应；连线不一定表示连续时间。 |
| 时间、剂量、有序趋势 | 折线、阶梯、点图 | 顺序、间隔、缺口和重复单位可辨；不自动添加拟合曲线。 |
| 两个连续变量 | 散点、hexbin、二维密度 | 重叠、非线性、分组与依赖；有依据时才加回归和置信带。 |
| 部分与整体 | 条形、堆叠、清楚标注的比例图 | 精确比较优先共同基线；保留有意义的类别顺序和总量。 |
| 矩阵或多变量 | 热力图、表格、小多图 | 色阶、单位、排序或聚类依据；精确数值重要时用表格。 |
| 多指标或权衡 | 表格、点图、散点、小多图 | 保留单位与优化方向，不平均成无定义的总分。 |
| 空间、几何与曲面 | 二维切片、等高线、三维图 | 选择保留研究关系的投影，处理透视、遮挡和尺度。 |
| 预测评估 | 性能曲线、校准图、混淆矩阵或指标图 | 跟随研究问题与实际预测数据，不强制所有分类结果补齐同类曲线。 |

## 样本量与信息密度

样本少时逐点展示往往更清楚，也可给出有意义的汇总。样本多时用透明度、分箱、ECDF、密度或分面减轻重叠。没有一个固定 n 能保证分布稳定或自动决定图型。

箱体表示中间 50% 的观测范围，不是 75%，也不是均值置信区间。小提琴平滑不是新增观测，需检查带宽、边界和支持范围。按 `source-data-and-statistics.md` 核对统计含义。

只有均值、区间或单次结果时，可忠实展示这些信息，不因无法画原始点阻断任务，也不编造点或追加未授权实验。

## 分组与面板

保留配对、嵌套和交叉设计的真实含义。不平衡或缺少组合不自动要求加权或混合模型，统计方法由估计目标和设计决定。

相关问题可共享多面板。比较同一量时考虑共同尺度，不同量或局部放大可用清楚标记的独立尺度。拆分或合并后核对正文与图注。

使用现有工具或 `plot-recipes.md` 实现，核对真实接口与输入。例中的种子、区间、星号、尺寸和标题是演示，不是实验事实或强制格式。按 `visual-pitfalls.md` 检查语义风险，在最终尺寸查看成品。
