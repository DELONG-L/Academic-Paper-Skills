# 解读数据剖析报告

用于陌生表格、可疑类型或复杂分组。`scripts/profile_data.py` 提供探索性摘要，不决定统计方法、图型或论文是否合格。

```bash
python scripts/profile_data.py results.csv --group group --group condition
```

## 核对报告与变量含义

| 输出 | 应核对什么 |
|---|---|
| Columns | 类型、非空数量、缺失值、单位与实际含义。 |
| Group structure | 样本与运行单位、实际组合、配对/嵌套关系、组间数量。 |
| Correlations | 探索性相关；检查分组、非线性和共享来源。 |
| Warnings / Chart suggestions | 调查线索，不是自动更改数据、检验或图型的指令。 |

类型推断只是启发式：数字编号不一定有大小顺序，0/1 可能是数值观测，日期字符串可能误判，短序列可能被当作分类或文本。根据数据字典在分析副本中明确类型，保留原始输入；空列与无法判断的列需显式处理。

## 样本、分布与分组

确认 n 表示行数、受试者、运行还是重复测量。同一受试者的多个时间点不能当作独立重复。样本少时考虑展示观测点；只有可信汇总时仍可如实作图，不补造分布。

偏度和跨量级提示不自动改变估计目标。偏态数据也可能需要报告均值；中位数和 IQR 应分别定义，不能写成对称的“中位数 ± IQR”。对数轴适合倍数关系，但先检查零值、负值、解释目标和单位。

不平衡组与缺失组合不自动要求加权或混合模型。采用既有分析计划，绘图任务不能静默重做正式统计分析。

## 缺失与异常值

排除、缺失与分母变化应可追溯。缺失比例小不代表可以无条件忽略，比例大也不自动决定插补或删样本。检查缺失分布及其对目标量的影响，按既有方案处理，不能仅凭百分比认定 MCAR/MAR/MNAR。

IQR 规则标出的点不是无效数据的证明。保留有效极端值；有据的方法学理由才允许排除，记录原值、原因和影响。必要信息放在 Methods、图注或对应分析位置，无需每图重复清单。

## 相关性与绘图

Pearson r 不覆盖所有非线性关系，也不建立因果关系。高相关不自动证明某列冗余，低相关不证明无关。按问题选择散点或分组检查，不为降维删掉必要变量。

用 `chart-selection.md` 选择表达关系，将转换写入可重建的过程。复核输出、原始来源及 `source-data-and-statistics.md` 的汇总要求。
