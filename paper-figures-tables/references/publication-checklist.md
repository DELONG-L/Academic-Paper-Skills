# 图表交付检查

按当前图表、交付阶段和已核实的投稿要求选择检查项。普通出图与正式投稿准备状态分开判断；风格偏好不建立硬门槛。

## 内容与统计

- 数值、单位、样本与运行次数能追溯到实际输入；正文、图表和图注一致。
- 区分有效但不利的结果、无效测量、模拟研究和布局占位值。
- 误差棒或区间说明其含义、分析单位与适用的样本量。没有做显著性检验时，不为满足图注格式补做或编造检验。
- 只有实际报告检验或显著性符号时，才交代相应方法、比较与校正。
- 用 `visual-pitfalls.md` 检查实际误读风险，不按图型名称或样本量阈值自动否决。

## 尺寸、格式与字体

- 从当前模板或官方要求确定最终宽度、有效字号、允许格式及位图分辨率；见 `journal-specs.md`。
- 精确图优先保留矢量文字与线条；照片、热力图或密集点层可以是适当分辨率的栅格内容。
- 源画布 3x、24pt 是可调整的绘图起点。判断实际放置后的可读性，不把源字号或固定英寸数当作投稿要求。
- 检查缺字、裁切、单位、数学符号和字体替换；格式转换本身不证明正确。

## 编码与版式

- 坐标刻度和范围准确，长度或面积编码不夸大差异；局部放大、转换和轴关系清楚。
- 颜色、线型、符号、图例或直接标注让比较可恢复，关键含义不依赖单一颜色。
- 图注解释所需的编码和条件；不强制追加 takeaway 或“不能证明什么”。
- 子图标签、共享含义的颜色和单位一致；独立尺度有清楚标记。
- 图片语言遵循用户、稿件和目标读者，不从字体或运行环境推断。

## 文件诊断与最终查看

`scripts/check_figure.py` 是只读诊断工具。无投稿来源时，格式和字体建议不代表 venue 硬约束。需要验证已确认的位图要求时显式传入，例如：

```bash
python scripts/check_figure.py figure.png --min-dpi 300 --width-in 3.5 --height-in 2.5 --strict
```

例中参数仅用于演示，应替换为实际要求。`--strict` 只控制确定性失败时的进程退出码，与 strict house style 无关。退出码 0 不代表来源、语义、全部字体或投稿准备状态已通过。

检查实际导出文件在最终放置尺寸下的渲染。内存画布预览可以提前发现问题，但不能替代最终导出检查。合并修复相关问题后再查看，不必为每个微小改动单独跑一轮。

记录检查过的文件、尺寸、结果和实际执行者。模型读图属于 agent 检查，不能写成 human evidence。正式评估中的 manual 项仍需要规定的人类、用户或 venue 证据；普通作图无需因此创建空合规文件或要求用户找非同行审图。
