# Learn Reusable Writing Decisions from Reference Papers

Use when asked to learn from a paper, an advisor's examples, or a set of writing
references. Read the relevant original passages, not just an abstract or a
reputation summary. Honor source access and quotation limits.

For each useful technique, record:

`source/version/locator | writing problem | decision | why it helps | where it fits | where it would mislead`

Extract decisions such as how a definition is introduced, evidence is ordered,
a contrast is substantiated, or a dense comparison is made readable. Identify
the relation between the technique and the paper's actual contribution. Do not
copy distinctive prose, infer acceptance causality from publication, or turn a
single author's habit into a universal rule.

Compare alternatives when the supplied corpus permits it: theory, measurement,
negative-result, and synthesis papers may need different structures. A repeated
pattern is evidence of a convention in that corpus, not proof that every paper
should follow it. Preserve contradictions and exceptions rather than averaging
them into a rigid template.

Useful candidate structures include checking an established assumption against
evidence; developing a definition into a derivation and then a method; or removing
a design component and testing the consequences under fair comparisons. These
are argument shapes to evaluate, not sentence templates or a requirement to beat
a benchmark. A descriptive or negative finding can justify a different shape.

Demonstrate an adopted technique on the user's supplied material or a clearly
labeled synthetic example. Check that the new wording uses only available facts.
Keep original and revised passages available so the user can judge the trade-off.

Return the requested analysis or example. Update reusable skill instructions only
when that update is authorized; do not automatically write personal memories or
install a new preference after ordinary literature reading. Existing author
decisions, including direct claims without anticipatory defense, govern adaptation.
