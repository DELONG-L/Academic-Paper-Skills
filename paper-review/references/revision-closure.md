# Decide Whether Further Revision Is Needed

Use at the end of substantial manuscript review or revision. Decide from the
remaining problem and inspected evidence, not the number of style suggestions.
This is an editorial conclusion, separate from formal submission readiness.

| Situation | Conclusion | Useful next action |
|---|---|---|
| Requested scope is coherent and supported; remaining suggestions are optional | Finish this revision | Deliver and retain optional advice without opening another polish loop |
| A concrete local defect remains and a supported fix is available | Complete a bounded fix | Name the cause, affected passages, fix, and how to verify it |
| A central claim or inference remains unsupported, or the argument needs reconstruction | Substantive work remains | Identify the evidence or author decision required; complete independent supported work |
| The material is partial, truncated, or missing essential sections | Whole-paper judgment unavailable | State inspected scope and missing material; still return useful local findings |

Use plain language; no new status vocabulary is required in the paper-policy
schema. A correctable formatting issue may remain after substantive editing
finishes. If formatting is part of the authorized task, fix it without reopening
unrelated prose. Do not label an unready submission READY just because rewriting
is finished.

Before another revision pass, identify what the pass will change and why that
could resolve the problem. If the same issue survived the last attempt, diagnose
the cause instead of repeating a cosmetic transformation. New evidence or a
different substantive fix may justify continuing; an arbitrary round count does
not justify stopping with required work unfinished.

Avoid stopping or continuing on detector scores, finding counts, imagined
acceptance probabilities, or the fact that wording could always be improved.
Do not relabel an unresolved central flaw as an acceptable limitation solely to
close the task. Conversely, do not turn an optional stylistic preference into a
substantive flaw.

For multi-round author responses, consult `revision-plan.md`: distinguish edits
that exist from promised edits, and verify current locations. A review note can
hold the closure decision and source revision; no additional file is required.

Example: the argument is complete, but an appendix reference points to the old
section number. Correct that reference and check the build. It does not require
another rewrite of the Introduction.

Example: only the Results excerpt was inspected. Finish its local edit without
asserting that the whole manuscript has a complete argument.
